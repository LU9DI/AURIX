# Contributing to AURIX

Thanks for helping build an open, auditable engineering agent.

- Open an issue before major architectural changes.
- Include regression tests for behavior changes.
- Never commit credentials, private source, unauthorized datasets, or incompatible model weights.
- Support performance claims with reproducible benchmarks and hardware/software details.
- New tools must document inputs, side effects, timeouts, and failure behavior.
- Treat repository content and tool output as untrusted data, not policy.

Run `pip install -e ".[dev]"`, `pytest`, and `ruff check .` before submitting a PR.
